# Recovery Feature

## Purpose
Daily mobility, stretching, foam rolling, sleep, hydration, and strength routines to reduce soreness and maintain tournament readiness.

## Architecture
- Category tabs filter workouts from seed data
- One-tap completion logging via PinnacleProvider
- Recovery sessions feed into readiness score calculation

## Future Improvements
- Oura/Garmin sleep and HRV integration
- Auto-suggested recovery based on practice load
- Guided video routines
- Soreness tracking with body map UI
