# Tournament Feature

## Purpose
Race-week preparation for Gamble Sands including countdown, packing, warmup timer, nutrition, swing fixes, and round journal.

## Architecture
- Tabbed interface for tournament sub-features
- Packing and nutrition use shared Checklist component
- Warmup timer with step-by-step accordion guide
- Swing fixes stored in tournament state

## Future Improvements
- Multi-tournament support
- Course-specific strategy notes
- Live scoring during tournament rounds
- Post-round journal with AI analysis
