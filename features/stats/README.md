# Stats Feature

## Purpose
Track scoring statistics, display trends, and identify patterns to drive improvement toward a 3 handicap.

## Architecture
- Round logging form with full stat capture
- Recharts line chart for score trends
- Stat cards for key averages
- Rounds persisted via PinnacleProvider

## Future Improvements
- GHIN/TheGrint auto-import
- Strokes gained analytics
- Fairway/GIR/putting trend charts
- Benchmarking against handicap goals
